# 商品清单输出结构

用户表达了交易意图但未明确具体商品时，返回商品清单供其挑选。buy / price / unsubscribe 各动作**共用**本结构。

先按本结构整理出完整字段，再按「渲染规则」输出为表格。

## 字段来源标记

本目录下的输出结构统一使用以下来源标记，决定字段能否取到、以及缺失时怎么处理：

| 标记 | 含义 | 缺失时 |
|---|---|---|
| `[本地]` | 取自 [product-catalog.md](./product-catalog.md) | 不可缺 |
| `[询价]` | 询价 OpenAPI 返回值 | 不可缺；缺则该条不展示 |
| `[商品]` | 商品 OpenAPI 返回值，**当前不可用** | 降级显示 code 或省略该列，**不得用模型推断填充** |
| `[流程]` | 动作流程内已确定的信息 | 不可缺 |
| `[模型]` | 允许模型生成的解释性文案 | 可省略 |

接口返回类字段（`[询价]`、`[商品]`）一律**原样透传**：不改写、不四舍五入、不换算币种、不做任何算术加工。

## 命名规范

本目录下所有输出结构的字段名一律使用**大驼峰**（PascalCase），与火山引擎 OpenAPI 的字段风格保持一致。新增字段时沿用该规范。

## 结构

```
ProductList
├── Title           [模型] 清单标题，按用户问法收敛，如「AI 商品清单」
├── Intro           [模型] 引导语，说明可按任务描述帮用户选型
├── Items[]         商品条目
│   ├── Name        [本地] 商品名称
│   ├── ProductCode [本地] 商品 code
│   └── Summary     [本地] 一句话能力描述
├── Total           条目总数
└── PageSize        每页条数，默认 5
```

## 渲染规则

- 渲染为表格，列为「商品 / 说明」；`ProductCode` 是流程内部字段，**不对客展示、也不在对客表述中提及**。
- 条目超过 `PageSize` 时只展示首页，末尾注明「共 N 条，回复商品名或"更多"继续查看」。
- 用户按品类提问（如"有哪些 AI 商品"）时，只列该分类下的商品。
- **清单内容只能来自 [product-catalog.md](./product-catalog.md)**，不得由模型补充未收录的商品。
- 清单为空或无匹配分类时，如实说明并引导用户前往火山引擎官网产品页浏览。

## 与各动作的衔接

用户从清单中选定商品后，回到当前动作的流程继续：

| 动作 | 后续 |
|---|---|
| buy | 按 [buy/product-rule.md](../buy/product-rule.md) 确定该商品的开通方式 |
| price | 取 `ProductCode` 继续询价 |
| unsubscribe | 取 `ProductCode` 查询该商品下的可退订实例 |
