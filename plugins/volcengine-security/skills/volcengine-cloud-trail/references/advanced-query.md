# TLS 高级检索

仅进入 TLS 检索或 SQL 分析时读取本文；导出读 [result-export.md](result-export.md)，模板管理读 [search-templates.md](search-templates.md)。身份、确认与输出遵循 [rules.md](rules.md)。

## 查询与分析

统计任务还需读取 [统计与核对](result-export.md#统计与核对)，确认计数单位和数据范围。

### 确认要查哪些日志、日志是否已保存

1. 确认本次查询的审计日志所属账号及要查询的 TLS 日志主题，核对实际调用身份是否具备查询权限；权限不足时，说明所需授权。
2. 查找已投递的日志时，按 [result-export.md 的“查找已投递的日志”](result-export.md#查找已投递的日志) 执行：先用已指定且核实的日志主题，否则检查包含组织范围的跟踪；缺少当前跟踪时继续检查已有上下文和历史任务指向的已投递日志。有多个日志主题时，先比较日志的时间和事件范围、访问权限与所属账号，不能可靠判断时才询问。
3. 从已核实的跟踪、历史任务或资源详情取得地域、项目和主题 ID，用于确定要查询的 TLS 日志主题；已验证 Topic 时可按 `volcengine-tls` 查询。
   多个跟踪共用 Topic 时，不将主题内全部日志直接归属于所选跟踪。
4. 时间输入与转换遵循主 SKILL.md 的时间与条件规则；具体时间参数及单位按 `volcengine-tls` 中对应操作的当前接口说明处理，不能混用。
   时间未提供且上下文无法推断时询问。核对日志时间与 `EventTime` 的实际写入关系，尤其是补投数据，不假定二者等同。
5. 无法确认日志是否包含所需时段和事件，但日志主题可访问时，可继续查询并说明哪些范围尚未核实；缺少可用的已投递日志时按 result-export.md 处理。

### 依赖与执行

- 执行 TLS 操作前读取当前可用的 `volcengine-tls`，按当前 CLI 命令说明执行。
- 检查 `volcengine-tls` 技能及其依赖是否可用；缺少依赖时明确缺项，按当前运行环境允许的方式安装。
- 具体执行流程遵循 `volcengine-tls`，不猜命令、参数或接口路径。
- 根据用户要查的操作选择模板或编写查询语句。检查实际日志字段和索引，不直接把基础检索返回的字段名用于 TLS 查询。
- 跟踪复用已有 TLS 日志主题时，不默认该主题已配置操作审计所需的索引。先检查实际字段及索引是否满足本次检索或分析需求；已满足时直接使用，无需重新建立索引。
- 索引不满足时，说明缺失项及对查询的影响，不擅自删除用户条件。需要修改索引配置或为历史日志重新建立索引时，先核实 TLS 支持的操作、历史数据生效范围及相关成本，明确对主题已有日志和查询的影响，并取得用户确认后再执行；不自动覆盖已有索引。
- 修改索引配置与为历史日志重新建立索引是两种不同操作。处理完成后重新核对索引及所查时间范围内的数据是否可查，不因配置修改成功就认定历史数据已可检索。
- 普通日志检索与 SQL 分析采用各自接口规定的分页方式。统计和全量查询需确认扫描及返回结果完整；结果不完整时明确说明，不将部分结果作为完整结论。

### 执行与结果

按当前 `volcengine-tls` 的接口说明执行日志检索或 SQL 分析，使用已核实的 TLS 身份、地域和服务地址。身份核实遵循 rules.md。

普通日志按返回游标续查，并固定账号、主题、绝对时间和查询条件；SQL 分析按语句及接口支持的方式分页。读取扫描状态和结果条数，说明实际覆盖范围。工具返回文件路径时，读取实际文件后解释结果。
